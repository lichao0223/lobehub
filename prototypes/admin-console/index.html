把当前机器注册进设备池

在要共享的机器上执行；需要管理员账号登录的 CLI。

1 · 注册（设备归当前管理员所有，pool = admin）
lh device pool register --name "A100 训练机"
2 · 分配给全员
lh device pool grant A100 --all
3 · 或只分配给指定人（工号 / 邮箱）
lh device pool grant A100 --user A100877

注册成功后刷新本页即可看到设备；也可以在设备页的分配抽屉里改授权范围。非管理员执行上述命令返回 FORBIDDEN。
