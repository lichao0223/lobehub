# 管理员控制台交互原型（第七版 · 模型服务）

直接双击用浏览器打开 `index.html` 即可，无需构建、无需依赖。纯静态，数据是 mock，不连接真实接口。

设计依据是仓库根目录的 [`ADMIN_CONSOLE_DESIGN.md`](../../ADMIN_CONSOLE_DESIGN.md)（第七版，已与本原型同步）：Tellhow 企业内置厂商、零模型下发。

## 模型服务页

一句话：**公司只维护一个内置服务商，不往用户设置里推任何东西。**

三张配置卡：

### 1. 服务连接

- **服务地址**：OpenAI 兼容 baseURL，用户侧不可见、不可改；保存后下一次请求生效。
- **访问密钥**：密码框直接展示，默认是掩码点；下方注明「上次更新：11-19 17:26 · 张伟 · 末四位 3f9c」。
  - 管理员在 Tellhow 网关生成 Key 后直接粘贴进来，点「保存配置」生效，没有单独的更换 / 轮换按钮；
  - **控制台不生成密钥**，也不回显完整内容；保存动作写入审计，但不记录密钥内容。
- **最近一次检测**：用已保存的密钥请求一次 `/models`，只回显状态、延迟和可用模型数；测试失败时标签变红并可重试。

### 2. 模型目录

- 列表列：模型（显示名 + id）、类型 + 能力、上下文、对全员开放、操作；
- **类型以 `packages/model-bank` 的 `AiModelType` 为准**，共 9 种：对话 `chat`、图片 `image`、视频 `video`、向量化 `embedding`、ASR `asr`、TTS `tts`、音乐 `text2music`、实时 `realtime`、决策 `decision`。
- **从服务拉取**：上游 `/v1/models` 只返回 id / owned_by / created，分类分三层：
  1. **规则推断类型**（弹窗里可逐个改）：
     - `embed|bge|gte|text-embedding` → 向量化
     - `music|suno|melody|text2music` → 音乐
     - `tts|speech|voice` → TTS
     - `whisper|asr|stt|transcribe|audio` → ASR
     - `dall-e|flux|diffusion|image|sd-` → 图片
     - `video|sora|veo|kling` → 视频
     - `realtime` → 实时；`decision` → 决策
     - 其余 → 对话（标注「需人工确认」）
     - 注意：**视觉不是类型**，`vl / vision / multimodal` 归为对话，视觉理解在编辑弹窗里作为「能力」勾选。
  2. **命中已有模型目录**（如 `qwen3-32b`、`deepseek-v3.2`）时带出显示名、上下文与能力；
  3. **未识别的模型**导入后打「待确认」标签，上下文显示 `—`，由管理员在编辑弹窗里补全。
- 类型筛选固定展示全部 9 种类型并带数量（对话 / 图片 / 视频 / 向量化 / ASR / TTS / 音乐 / 实时 / 决策）；没有模型的类型也保留并置灰，点进去给空态提示，避免「看不到这个类型就以为不支持」。
- 同步策略：新增默认**不开放**、标「待确认」；已存在的只更新元数据；上游消失的模型**不自动删除**，标「上游已移除」，确认无人使用后再手动移除。
- **编辑**（每行「编辑」）：可改显示名、类型（9 种全量下拉）、上下文长度、能力（工具 / 推理 / 视觉）、对全员开放，也可「从目录移除」；保存后立即生效。
- 「手工添加」用于网关没有暴露 `/v1/models` 的情况：填 id、显示名、类型（同样 9 种），默认不开放。
- 开放开关只控制用户侧模型列表可见性，不写任何用户数据。

### 3. 默认值（可选）

- 新用户默认对话模型、记忆向量、历史压缩 / 标题生成、任务校验；
- 定位是「默认值，用户可改」，不是托管；记忆向量旁注明换模型需重新索引。

保存只提示「已保存地址与默认值；未修改任何用户设置」，不再有「将同步 N 位用户」这类确认。

> 命名：侧栏与页面标题用「模型服务」，备选「AI 接入」「企业 AI」。选定后把设计文档与代码里的 `model-service` 对齐即可。

## 视觉基线

原型不另造后台风格，直接复刻现有「设置」页：

- 外壳按 `src/features/Settings/Layout`：左侧 NavPanel（280px，`colorBgLayout` 背景，loose 密度：44px 页头、36px 导航项 / 14px 文字 / 28px 图标盒）+ 右侧 44px 页头；
- 侧栏分组按 `Settings/Layout/Body`：搜索框（`SearchBar variant="filled"`，36px 高、`fill-tertiary`）+ 分组标题 + 组内 `gap: 1px` 的导航项；
- 内容区 `MAX_WIDTH = 1024`，`paddingBlock: 24px 128px`、`paddingInline: 24px`；
- 字号只用 12 / 14 / 16 三档；间距走 4px 栅格；控件高度 36（`controlHeight`），输入圆角 6、按钮圆角 8、标签圆角 4；
- 三个列表都用设置页的列表形态：小号列头 + 12px 行内边距 + 发丝分隔线 + hover 填充，不再用带边框的 HTML 表格；
- 页面标题只由顶栏绘制，内容区不再重复 H1（与 `SettingsContent` 一致），页面内只保留说明文字与操作；
- 卡片复刻 `@lobehub/ui` 的 `Form variant="filled" itemsType="group"`：外层 12px 圆角 `fill-quaternary` 承载，内层 `colorBgContainer` 卡片（`margin: 0 3px 3px`、8px 圆角、1px `colorBorderSecondary` 边框；浅色叠 4 层阴影，深色无阴影）；
- 颜色、圆角、阴影全部走 `--lobe-color-*` / `--lobe-radius*` / `--lobe-shadow-*` token，取值对齐 `@lobehub/ui` 的 `theme.css`（主色 `#222222`，深色下反转为 `#eeeeee`），右上角按钮切换深浅色。

## 用户管理 / 审计

这三页与上一版一致，这里只记要点：

- **用户管理**：搜索（工号 / 姓名 / 邮箱）、筛选（全部 / 管理员 / 已禁用）、按工号升序；行 → 520px 详情抽屉（概览 / 操作）；禁用、设 / 撤管理员、会话失效各落一条审计。
- **审计日志**：完整时间戳（`YYYY-MM-DD HH:mm`）、操作者、动作标签、目标、来源 IP；行尾 chevron 指示可展开，支持鼠标点击与键盘 Enter / 空格；展开后以「变更前 / 变更后」两行对照展示，敏感值不入库也不展示；底部标注「按时间倒序，最新在前」与页码；无结果时给空态和「清除筛选」。

## 演示辅助

所有交互都是本地 mock：开关、筛选、测试连接、更换密钥、添加模型、保存都在当前页面内反馈，刷新即还原。原型不连接任何真实接口，也不代表最终接口形态。
