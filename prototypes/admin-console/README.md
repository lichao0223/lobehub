# 管理员控制台交互原型

直接双击用浏览器打开 `index.html` 即可，无需构建、无需依赖。

可点击的内容：

- 左侧「总览 / 用户 / 默认配置」切换；
- 用户列表搜索、筛选；
- 点击任意用户行，打开右侧详情抽屉；
- 详情抽屉内切换「概览 / 实验室 / 模型与权限 / 操作」；
- 「默认配置」页的开关、下拉框；
- 底部「保存并应用…」打开应用范围确认框（仅补齐未设置项 / 强制覆盖）。

设计与实现方案见仓库根目录 [`ADMIN_CONSOLE_DESIGN.md`](../../ADMIN_CONSOLE_DESIGN.md)。

> 这是纯静态原型，不连接真实接口，也不会修改任何产品代码。
