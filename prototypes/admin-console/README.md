# 管理员控制台交互原型（第五版）

直接双击用浏览器打开 `index.html` 即可，无需构建、无需依赖。纯静态，数据是 mock，不连接真实接口。

设计与实现方案见仓库根目录 [`ADMIN_CONSOLE_DESIGN.md`](../../ADMIN_CONSOLE_DESIGN.md)。原型覆盖设计里的五个页面，侧栏顺序为 用户管理 → 审计日志 → AI 服务商 → 服务模型 → 设备，对应交付批次：P1 上线用户管理与审计日志，AI 两页在 P2 出现，设备在 P3 出现。没有外观、快捷键、数据统计页，也没有「用户设置模板」页。

## 五个页面

| 页面      | 路由 key        | 上线批次 | 管理员专属 |
| --------- | --------------- | -------- | ---------- |
| 用户管理  | `users`         | P1       | 否         |
| 审计日志  | `audit`         | P1       | 否         |
| AI 服务商 | `provider`      | P2       | 是         |
| 服务模型  | `service-model` | P2       | 是         |
| 设备      | `devices`       | P3       | 否         |

AI 两页是现有「设置 → AI 服务商」页的 **1:1 复刻**，不是另画一套后台风格；管理员与普通用户看到的是同一套界面，区别只在写入目标是全局策略、且非管理员看不到入口。

## 视觉基线

原型不另造后台风格，直接复刻现有「设置」页：

- 外壳按 `src/features/Settings/Layout`：左侧 NavPanel（280px，`colorBgLayout` 背景，loose 密度：44px 页头、36px 导航项 / 14px 文字 / 28px 图标盒）+ 右侧 44px 页头；
- 侧栏分组按 `Settings/Layout/Body`：搜索框（`SearchBar variant="filled"`，32px 高、`fill-tertiary`）+ 分组标题 + 组内 `gap: 1px` 的导航项；
- 内容区 `MAX_WIDTH = 1024`，`paddingBlock: 24px 128px`、`paddingInline: 24px`；
- 卡片复刻 `@lobehub/ui` 的 `Form variant="filled" itemsType="group"`：外层 12px 圆角 `fill-quaternary` 承载，内层 `colorBgContainer` 卡片（`margin: 0 3px 3px`、8px 圆角、1px `colorBorderSecondary` 边框；浅色叠 4 层阴影，深色无阴影 —— 对应 `groupStyles.bodyFilledLight` 只在浅色挂载）；
- 颜色、圆角、阴影全部走 `--lobe-color-*` / `--lobe-radius*` / `--lobe-shadow-*` token，取值对齐 `@lobehub/ui` 的 `theme.css`（主色 `#222222`，深色下反转为 `#eeeeee`），右上角按钮切换深浅色。

## AI 服务商

复刻 `src/features/Settings/provider`：

- **服务商菜单**（对应 `ProviderMenu/List`）：顶部「全部」入口（原版 `All.tsx`）+ 三段可折叠分组「已启用服务商 / 未启用自定义服务商 / 未启用服务商」，每段带计数与排序入口；搜索框按名称 /id 就地过滤；
- **全部视图**（对应 `(list)/ProviderGrid`）：进入时 240ms 骨架（12 张，对齐 `loadingArr`）后渲染分组卡片网格（`Grid gap 16`）；卡片含 Logo、名称、Coding Plan / 自定义标记、说明、已启用模型数、启停开关；
- **服务商详情**（对应 `detail/default`）：面包屑 → Logo + 名称 + 「自定义 / 内置服务商・模型数・已启用数・配置对全部用户生效」→ 配置行（API Key、API 代理地址、客户端请求）→ 模型列表；「检查」按钮 600ms 后回「连接正常・312ms」，对应原版 `Checker`；
- **模型列表**（对应 `features/ModelList`）：Tab 顺序与原版 `allTabs` 一致（全部 → 对话 → 图像 → 视频 → 向量 → 语音识别 → 语音合成 → 音乐 → 决策），计数内联在标签里（如 `全部 (24)`，对齐原版 `formatTabLabel`）；「已启用 / 未启用」两段分组，行内开关、编辑、删除、类型标签；搜索与当前 Tab 组合过滤；
- **全局配置语义**：API Key 与代理地址由管理员统一维护，密钥不向用户端下发；「客户端请求」保持关闭即托管模式。

菜单顶部脚注显示「共 94 个服务商・12 个已启用」。mock 规模：94 个服务商（12 个已启用，含公司网关 `custom-gw` 与内网 vLLM `custom-vllm`）、1847 个模型，另含 `openai` / `google` / `ollama` 三个服务商下默认停用的模型样例。

## 服务模型

- 四个层级（main /flash/verify /embedding，按 `SERVICE_MODEL_TIER_SLOTS` 展开到 19 个槽位），写入 `system_agent` 的托管槽位；
- 每行 = 槽位名 + 说明 + 模型下拉（按已启用服务商分组，无空组）；记忆类槽位额外带条数上限与提示词；
- 高级槽位默认折叠（`toggleAdvanced`），主模型改动后「保存并同步」弹出变更摘要与影响人数，「还原」回到上次保存状态。

## 用户管理

- 搜索（工号 / 姓名 / 邮箱）、筛选（全部 / 管理员 / 已禁用）、按工号排序；
- 行内看角色、状态、分配到的设备数、最后活跃；
- 点击行打开 520px 详情抽屉：「概览 / 设备授权 / 操作」三个 tab；
- 操作 tab 里禁用 / 启用、设 / 撤管理员、会话失效，每个动作落一条审计（在「审计日志」页立即可见）；
- 底部备注说明账号来自 SSO，这里不新建账号体系。

## 设备

- 设备池列表：名称、主机、平台、在线、授权范围（全员 / 指定人 / 未分配）、最近活跃；
- 行 → 分配抽屉：切换「全员 / 指定人」，指定人模式按工号或邮箱搜索勾选；
- 撤销授权：运行中的任务不中断，下一次刷新用户就看不到；
- 「注册设备…」弹窗给出 `lh device pool register` / `grant` 三条命令，说明非管理员执行返回 `FORBIDDEN`；
- 「预览空态」演示池里还没有设备时的提示。

## 审计日志

- 时间倒序，按操作者 / 目标 / 动作搜索，按账号 / 配置 / 设备筛选；
- 点行展开前后值与来源 IP；
- 说明：只在写操作成功后落库，失败不记录；Key、token 之类敏感值不入库。

## 用户设置里的 AI 菜单

控制台只有管理员能进，所以侧栏没有「切换视角」这类入口；菜单可见性是控制台里的一项配置，落在「服务模型」页顶部的「用户设置里的 AI 菜单」卡片：

- 两个开关分别决定普通用户在自己的「设置」里能否看到「AI 服务商」与「服务模型」；
- 关掉后该项从用户设置中消失，直达 URL 被拦回设置首页，服务端写入同样返回 `FORBIDDEN`；
- 卡片底部实时给出结果摘要：「用户侧『设置』中可见：AI 服务商、服务模型」或「不显示任何 AI 菜单」。

## 演示辅助

上述两个菜单开关是演示里唯一影响用户侧的动作；纯演示动作（排序、编辑模型、拉取模型列表等）只弹 toast，不改变数据。

> 默认值取自当前仓库的 `DEFAULT_SETTINGS`、`DEFAULT_AGENT_CONFIG`、`DEFAULT_LLM_CONFIG` 与 `DEFAULT_SYSTEM_AGENT_CONFIG`，并按第五版设计里的 mock 用户 / 设备 / 审计数据渲染。
